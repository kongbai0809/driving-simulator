# 拟真驾驶模拟器 🚗🚄🚂

一个基于原生 WebGL 的 3D 拟真驾驶模拟器，单文件 HTML 实现，无需任何外部依赖。支持汽车、高铁、蒸汽机车三种载具切换，以及警察追击模式。

## ✨ 功能特点

### 🚗 三种载具
- **高速公路汽车** — 手动挡模拟，含离合、油门、刹车、6 档变速、熄火机制
- **高铁动车组** — 牵引级位控制、再生制动、定速巡航、站点停靠判定（北京南→上海虹桥）
- **蒸汽机车** — 锅炉压力模拟、加煤注水、汽门控制、安全阀排气

### 🚨 警察追击模式
- 一键开启警察追击，警车 AI 实时追赶
- 警灯闪烁 + 警笛音效
- 被抓获判定与通缉系统

### 🎮 拟真物理
- 120Hz 固定步长物理引擎
- 汽车：扭矩曲线、换挡冲击、熄火保护、轮胎黏着
- 高铁：牵引力-速度曲线、轮轨空转、再生制动回收
- 蒸汽：锅炉热力学、蒸汽消耗、水位保护

### 🎛️ 专业 HUD
- 双仪表盘（转速表 + 时速表），SVG 指针 + 弧形进度
- 载具状态面板（水温/油温/增压/健康度等）
- 功率/牵引力实时曲线图
- 天气与时间系统（昼夜循环、晴/雨/雪）
- 路线/站点信息
- 6 项迷你指标卡（节气门、制动、燃料、黏着等）

### 🔊 音频引擎
- Web Audio API 实时合成
- 汽车引擎声（锯齿波+方波叠加，随 RPM 变化）
- 高铁电机声、风噪
- 蒸汽机排气声、汽笛、铲煤音效
- 警笛声、喇叭声

### 🎨 3D 渲染
- 原生 WebGL（无 Three.js 等框架）
- 程序化纹理（沥青、混凝土、金属、草地、木材、煤）
- 第一人称驾驶舱视角（方向盘、仪表台、座椅、后视镜、雨刷）
- 动态天空（昼夜渐变、太阳、星空）
- 雾效、光照、高光
- 远景山脉、城市天际线、NPC 车辆

## 🎯 操作说明

### 汽车模式
1. 长按【离合】→ 按【＋】挂入 1 档
2. 同时按住【油门】→ 缓慢松开【离合】起步
3. 升档：踩离合 → 按＋ → 松离合
4. 刹车：右侧滑块上下拖动
5. 熄火后：踩离合 + 油门重新点火

### 高铁模式
- 【▲】增加牵引级位，【▼】减少
- 右侧滑块控制制动
- 【定速】开启/关闭定速巡航
- 进站需在停车标前精准停车

### 蒸汽模式
- 长按【加煤】提升火势和锅炉压力
- 长按【汽门】开大调汽（松开保持当前开度）
- 长按【注水】补充锅炉水位
- 压力过高时安全阀自动排气

## 🛠️ 技术栈

- **渲染**：原生 WebGL 1.0（自定义矩阵库、Shader、Mesh 构建）
- **物理**：自定义固定步长物理引擎（120Hz）
- **音频**：Web Audio API（振荡器 + 噪声缓冲 + 滤波器）
- **UI**：纯 HTML/CSS（SVG 仪表盘、Canvas 功率曲线）
- **输入**：Pointer Events（支持触屏多点操作）
- **存储**：localStorage（设置持久化）
